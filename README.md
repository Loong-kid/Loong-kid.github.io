# Loong-kid.github.io

Root GitHub Pages site for Loong Kid games.

- `/` game portfolio (marketing URL for every app)
- `/support/` contact and FAQ (support URL for every app)
- `/privacy/` privacy policy for all games
- `/app-ads.txt` AdMob verification — keep at the root

Add a new game: copy one `<article class="game">` block in `index.html`, add the icon to
`assets/icons/`, and add it to the "Games covered" list in `support/index.html`.
